# 背景管理

从 **设置 → 个性化 → 背景 → 背景管理** 进入。设置页和管理页的 **显示背景** 是同一个开关，关闭后主窗口所有页面都会恢复普通底色。

切到其他设置分类或主标签页后，再回到个性化会显示设置首页。已选择的背景不会改变，可再次点击 **背景管理** 打开图库。

当前背景的名称显示在页面标题旁。鼠标悬停可查看完整名称；本地背景还会显示它在图库中的相对路径。

## 收藏夹

在 **本地** 或 **Wallpaper** 图库勾选卡片右上角，即可把素材加入 **收藏夹**。再次点击可取消收藏，不会删除原文件；如果移除的是收藏夹当前固定的背景，需要重新选择。点击卡片本身会切换到这张背景，保持原来的播放方式。

要混合播放本地和 Wallpaper 素材，先切到 **收藏夹**，再选择 **启动时随机** 或 **定时轮播**。暂时找不到的素材会跳过；没有可用收藏时显示普通底色，不会换到未收藏的素材。收藏只记住引用，不复制文件。

## 本地背景

1. 点击 **打开本地背景文件夹**，把文件放进启动器目录下的 `ELCL/backgrounds/`。在个性化的 **背景** 卡片，以及背景图库的 **本地** 和 **收藏夹** 分类，都能找到这个按钮。
2. 点击 **刷新背景**。图库会列出背景目录及各级子文件夹里的图片和视频，不读取链接指向的目录。视频封面使用 Windows 生成的缩略图，画面不一定是第一帧。Windows 无法生成缩略图时，卡片会显示播放图标。
3. 在 **本地** 分类点击卡片即可切换到这份素材。当前背景会被标记；视频在主窗口循环播放，默认静音。

子文件夹里的背景卡片会显示所在目录，悬停可查看完整的相对路径。不同目录里的同名文件可以分别选择。

收藏夹、本地和 Wallpaper 图库都可以**搜索**或按**素材类型**筛选。搜索支持作品名、文件名和相对路径，不区分大小写；素材类型可选择全部类型、图片或视频。

图片支持 PNG、JPG、JPEG、BMP 和 GIF（只显示首帧）；视频支持 MP4、M4V、MOV、WMV 和 AVI，能否播放取决于 Windows 是否支持其中的编码。建议优先使用 H.264 编码的 MP4。

## Wallpaper Engine 素材

在 **背景图库** 选择 **Wallpaper**，即可看到 Steam 库里已下载的 Wallpaper Engine 创意工坊壁纸和已保存的本地项目。新增素材后可点击 **刷新背景**。即使 Wallpaper Engine 没有运行，ELCL 也能读取已下载的项目。引用的素材留在原目录，不会复制到 ELCL 或随配置导出。

**Wallpaper** 分类只支持固定背景。点击卡片会固定该素材；尚未选过时，先显示普通底色。这里仅列出可直接使用的图片和视频；场景（含 3D）、网页和应用壁纸不会显示，即使它们自带封面。

Wallpaper 图库还有**年龄分级**筛选，可选择**全年龄**、**建议家长指导**、**仅限成人（18+）**或**未分级**。分级来自 Wallpaper Engine 项目；没有分级或分级无法识别的素材归为**未分级**。默认显示全部分级，可以与素材类型一起筛选。

筛选只改变图库中显示的卡片，不影响当前背景、自动播放范围或**清空背景**的范围。

要随机或轮播 Wallpaper 素材，把它加入收藏夹，再切到 **收藏夹** 分类播放。找不到固定的 Wallpaper 素材时会恢复普通底色，可以刷新图库或另选一个背景。

## 播放方式

先选择分类，再选择播放方式。**本地** 和 **收藏夹** 支持下表的三种模式，**Wallpaper** 只能固定。切换分类会切换实际播放范围，并恢复该分类上次的播放方式或固定背景。启动器重开后会回到上次使用的分类。

| 模式 | 效果 |
| --- | --- |
| 启动时随机，默认 | 每次启动随机选一份，切页时保持不变。 |
| 固定背景 | 下次启动仍使用同一文件。文件被移走或无法打开时显示普通底色，直到你换一个或恢复文件。 |
| 定时轮播 | 本地图库按相对路径排序；使用收藏夹时，按加入收藏的顺序循环。两类分别记住上次播到的背景，下次启动时从那张重新计时。 |

在 **本地** 或 **收藏夹** 点击卡片不会改变播放方式。使用 **定时轮播** 时，会从点选的背景重新计时，再按原顺序切换；使用 **启动时随机** 时，这次点选不会影响下次启动。只有已经选择 **固定背景** 时，点选才会记住这张作为固定背景。

选中 **定时轮播** 后，在 **切换间隔** 输入分钟和秒，例如 `02:30`，也可以直接输入秒数，例如 `150`。支持 10 秒至 60 分钟，按 Enter 或离开输入框保存。

随机或轮播范围内有至少两项素材时，可以用标题栏右侧的 **上一张** 和 **下一张** 切换。轮播会从实际显示的那张重新计时，只记住壁纸，不记录倒计时或视频播放到的秒数。上次的壁纸不在图库里时，会从该分类的第一项可用素材开始。

自动模式会跳过打不开的文件。在 **背景设置** 开启 **后台播放** 后，最小化 ELCL 或切到其他窗口时，背景视频仍会按设定音量播放，定时轮播也会继续。

**后台播放** 默认关闭。离开 ELCL 主窗口时，视频和轮播都会暂停。切回来后，视频从暂停处继续，轮播重新计时。

拖动 ELCL 窗口、调整窗口大小或打开下拉菜单时，背景会停在当前画面，不受 **后台播放** 开关影响。拖动结束或关闭菜单后，如果当前允许播放，视频从暂停处继续，轮播重新计时。

在下拉菜单内滚动可以浏览选项。把指针移到菜单外的页面，一次滚轮操作就能收起菜单并滚动页面。

大尺寸图片会按载入时的窗口大小缩小后显示，不会修改原文件。

## 外观与声音

在页面上方的 **背景设置** 可调整播放方式、自适应、不透明度、模糊和视频音量。填满窗口可能裁剪边缘，完整显示可能留边，拉伸会改变原比例。模糊只影响图片或视频。

**卡片不透明度** 与 **导航栏不透明度** 可以分开调整。后者控制顶部导航栏和侧边栏的底色，不会淡化文字和图标。默认是 90％，0％ 为底色全透明，100％ 为实色。拖动时实时预览，设置会自动保存；没有显示壁纸时，导航栏保持实色。

**清空背景** 只在 **本地** 标签页提供。确认后会永久删除本地图库里的图片和视频，包括已收藏的本地背景。目录结构、其他文件和 Wallpaper Engine 素材不受影响。重置个性化只恢复播放与外观设置，保留收藏且不删除文件。
