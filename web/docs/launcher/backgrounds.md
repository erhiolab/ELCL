# 背景管理

从 **设置 → 个性化 → 背景 → 背景管理** 进入。设置页和管理页的 **显示背景** 是同一个开关，关闭后主窗口所有页面都会恢复普通底色。

切到其他设置分类或主标签页后，再回到个性化会显示设置首页。已选择的背景不会改变，可再次点击 **背景管理** 打开图库。

## 本地背景

1. 在底部的 **背景图库** 选择 **本地**，点击 **打开文件夹**，把文件放进启动器目录下的 `ELCL/backgrounds/`。
2. 点击 **刷新背景**。图库会列出背景目录及各级子文件夹里的图片和视频，不读取链接指向的目录。视频封面使用 Windows 生成的缩略图，画面不一定是第一帧。Windows 无法生成缩略图时，卡片会显示播放图标。
3. 点击任意卡片即可固定该文件。当前背景会被标记；视频在主窗口循环播放，默认静音。

子文件夹里的背景卡片会显示所在目录，悬停可查看完整的相对路径。不同目录里的同名文件可以分别选择。

图片支持 PNG、JPG、JPEG、BMP 和 GIF（只显示首帧）；视频支持 MP4、M4V、MOV、WMV 和 AVI，能否播放取决于 Windows 是否支持其中的编码。建议优先使用 H.264 编码的 MP4。

## Wallpaper Engine 素材

在 **背景图库** 选择 **Wallpaper**，即可看到 Steam 库里已下载的 Wallpaper Engine 创意工坊壁纸和已保存的本地项目。新增素材后可点击 **刷新背景**。即使 Wallpaper Engine 没有运行，ELCL 也能读取已下载的项目。引用的素材留在原目录，不会复制到 ELCL 或随配置导出。

点击卡片会固定该素材。支持的图片和视频可直接显示；场景、网页、应用等无法直接播放的壁纸仅显示项目自带的静态预览图，没有可用预览的项目不会列出。ELCL 不会运行壁纸里的网页或应用。

Wallpaper 素材只支持固定背景，不参加随机或定时轮播。切换到随机或轮播时，使用的是 **本地** 图库。找不到固定的 Wallpaper 素材时会恢复普通底色，可以刷新图库或另选一个背景。

## 播放方式

| 模式 | 效果 |
| --- | --- |
| 启动时随机，默认 | 每次启动随机选一份，切页时保持不变。也可以点击 **下一张** 换一份。 |
| 固定背景 | 下次启动仍使用同一文件。文件被移走或无法打开时显示普通底色，直到你换一个或恢复文件。 |
| 定时轮播 | 按相对路径顺序循环（先比较文件夹名，再比较文件名）。可选择从 10 秒到 60 分钟的切换间隔，也可以手动切换下一张。 |

自动模式会跳过打不开的文件。窗口最小化时会暂停视频和轮播计时，恢复后重新开始计时。

## 外观与声音

在页面上方的 **背景设置** 可调整播放方式、自适应、不透明度、卡片不透明度、模糊和视频音量。填满窗口可能裁剪边缘，完整显示可能留边，拉伸会改变原比例。卡片不透明度只影响底色，模糊只影响图片或视频。

**清空背景** 只在 **本地** 标签页提供。确认后会永久删除本地图库里的图片和视频，包括子文件夹中的背景。目录结构、其他文件和 Wallpaper Engine 素材不受影响。重置个性化只恢复播放与外观设置，不删除文件。
