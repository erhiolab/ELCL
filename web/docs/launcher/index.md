# ELCL 使用指南

首次打开时，先阅读[用户协议与免责声明](terms.md)，再单独选择是否允许[匿名统计](privacy.md)。不同意协议会退出；拒绝统计不影响使用。

ELCL 是 Minecraft Java 版启动器。第一次使用，按下面三步就能开始：

1. 在启动页打开 **账户管理**，添加 Microsoft 账户或离线账户。
2. 打开 **下载**，选择 Minecraft 版本和需要的加载器，完成安装。
3. 回到启动页打开 **版本选择**，选中游戏，再点击启动按钮。

已经安装过游戏？可以直接[添加已有游戏文件夹](versions.md)，不必重新下载。

## 当前边界

ELCL 固定按版本隔离存档、Mods 和游戏设置，共享支持库与资源。启动选项默认跟随全局，也可以在版本设置中逐项覆盖；独立设置和描述保存在版本目录内。

可以从版本选择页的 **导入整合包** 按钮，或将 ZIP／MRPACK 拖到启动页、版本选择页，导入 Modrinth、CurseForge 和 MultiMC 格式的包。详见[导入整合包](modpacks.md)。单独安装加载器不会顺带下载 Fabric API 或 Mods；需要的 Mods 可以在下载页另行安装。
