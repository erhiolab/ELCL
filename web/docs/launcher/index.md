# ELCL 使用指南

ELCL 是 Minecraft Java 版启动器。第一次使用，按下面三步就能开始：

1. 在启动页打开 **账户管理**，添加 Microsoft 账户或离线账户。
2. 打开 **下载**，选择 Minecraft 版本和需要的加载器，完成安装。
3. 回到启动页打开 **版本选择**，选中游戏，再点击启动按钮。

已经安装过游戏？可以直接[添加已有游戏文件夹](versions.md)，不必重新下载。

## 当前边界

ELCL 固定按版本隔离存档、模组和游戏设置，共享支持库与资源。启动选项目前是全局设置；版本独立配置目前保存自定义描述。

界面中的整合包导入尚未实现。安装加载器也不会顺带下载 Fabric API、模组或整合包内容。
