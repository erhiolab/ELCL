# 百宝箱

入口：**更多 → 百宝箱**。这里提供一些与游戏启动分开的实用工具。

## 下载自定义文件

1. 填写下载地址，ELCL 会尝试从 URL 自动填写文件名。
2. 选择保存文件夹，按需修改文件名。
3. 点击 **开始下载**，到[任务列表](tasks.md)查看进度或取消。

下载地址有效后才可以开始。**打开文件夹**打开目标目录，不会重新下载。

使用设置中的连接数和限速。需要登录、Cookie 或专用下载接口的网站可能返回 403，例如部分网盘链接；能在浏览器打开的页面地址不一定是文件直链。

## 今日人品

按电脑本地日期计算 0～100 的娱乐分数，同一天保持不变，不依赖登录或联网。

当天第一次点击时会从对应分数范围抽取一句文案，并保存到配置；之后点击或重启仍显示同一句。第二天第一次点击时重新抽取。

第一次使用要确认免责声明。清理缓存不会清除当天的文案记录。修改系统日期会影响结果。

## 清理游戏垃圾

点击后直接清理，不会重启。范围是已添加的游戏根目录和各版本目录里的 `logs`、`crash-reports`、`cache`、`.cache`、`server-resource-packs`。存档、Mods、截图、版本文件、共享支持库和资源不会移除。ELCL 自己的缓存和日志也不会动。

排查故障时请先备份需要的游戏日志和崩溃报告。没有版本目录、启动器档案等 Minecraft 标记的非 `.minecraft` 文件夹不清理。

## 清理 ELCL 缓存

点击后 **自动重启 ELCL**，在新窗口打开前清理 `ELCL/cache/`。清理后，皮肤、披风、游戏版本列表等会按需重新获取；配置、账户、背景原文件、启动器日志和游戏文件不会删除。

两种清理都没有确认弹窗。请先结束下载、安装和正在运行的游戏。遇到正在使用、受权限限制或链接指向的文件时，不会强制删除。完成后通知会显示删除文件数、释放容量和跳过或失败的数量。自动清理只回收 ELCL 的过期缓存，见[缓存保留规则](files.md#缓存保留规则)。

## 内存优化

与 **设置 → 启动 → 内存分配** 中的按钮执行相同操作，结果通过通知条显示。

它整理 Windows 工作集，不等于 Java 垃圾回收，也不保证提升帧率。详见[内存优化](launch-settings.md#内存优化)。

性能监控已单独放在 **更多 → 性能**，见[性能页面](performance.md)。
