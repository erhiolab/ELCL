# 百宝箱与性能

## 今日人品

“更多 → 百宝箱”的今日人品按电脑的本地日期计算 0～100 的数值。同一天重复点击、关闭后重新打开，结果都相同。它只是娱乐功能，不代表真实运气，不需要联网，也不依赖账号。修改系统日期会影响结果。

分数和文案在当天都会保持不变。每天第一次点击时，提示文案会从对应分数范围的六条文案中随机挑选，并与当天日期一起保存到配置中；当天再次点击、切换页面或重启 ELCL，都会显示第一次抽到的那句。第二天首次点击时重新抽取文案，不保证与前一天不同。文案分为 0、1～19、20～39、40～59、60～79、80～99、100 七组，共 42 条，低分也会收到温柔的猫娘鼓励。清理缓存不会清除当天记录，重置配置则会清除。

首次点击会显示免责声明，确认后记入配置，不再重复显示；换用一份未确认过的配置时会再次提示。

## 清理游戏垃圾

点击“清理游戏垃圾”会直接开始清理，不再弹出确认窗口。清理范围包括已添加游戏文件夹的 `logs`、`crash-reports`、`cache`、`.cache`、`server-resource-packs`，以及各版本内的同名目录，同时清理 ELCL 的全部缓存和旧日志。包括刚下载的皮肤、披风、版本清单及安装缓存，不再保留一天内的缓存。

有下载、安装或正在运行的游戏时，需要先结束这些任务。清理期间暂停界面操作，完成后自动重启 ELCL；新进程等待旧进程退出，再清扫可能晚到的缓存写入和旧日志，然后开始新的日志会话、重新加载界面。重启后的通知会合计两次清扫的文件数和释放容量。皮肤、披风和版本列表会在需要时重新获取，刚生成的新缓存属于正常使用。

存档、模组、截图、版本文件、账户、配置、共享支持库和游戏资源不会清理。被占用或无权限的文件与链接目录会跳过，不会强制结束其他程序来删除文件。当前运行日志在重启前保留，重启后作为旧日志清扫，新的运行日志会正常建立。

操作在后台进行，通知条显示成功删除的文件数、实际释放的容量、跳过和失败的数量。被占用或无权限的文件会保留，异常写入日志。删除的日志和崩溃报告无法从这里恢复，需要排查问题时请先备份。

## 内存优化

百宝箱的内存优化与“设置 → 启动 → 内存分配”共用同一个服务，不会重复开启并发扫描。具体限制见[内存优化说明](launch.md#内存优化)。

## 性能

“更多 → 性能”显示系统版本、处理器、逻辑处理器数量、显示适配器和启动器架构。实时区显示系统 CPU、物理内存、ELCL 自身 CPU 与工作集，以及游戏所在磁盘的可用容量。

刷新间隔可选 0.5、1、2、5 或 10 秒，会保存到配置。页面隐藏后停止周期采集，重新进入时重新采样。CPU 使用率需要比较两次读数，首次进入的第一帧为零。容量显示沿用个性化设置中的 GB / GiB 选项。

这是轻量概览，不提供进程列表、GPU 实时负载或硬件温度。硬件信息在后台读取；采集失败写入日志，避免每帧发送通知。
