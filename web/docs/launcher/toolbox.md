# 百宝箱

入口：**更多 → 百宝箱**。这里提供一些与游戏启动分开的实用工具。

## 下载自定义文件

1. 填写下载地址，ELCL 会尝试从 URL 自动填写文件名。
2. 选择保存文件夹，按需修改文件名。
3. 点击 **开始下载**，到[任务列表](tasks.md)查看进度或取消。

下载地址有效后才可以开始。**打开文件夹**打开目标目录，不会重新下载。

使用设置中的连接数和限速。需要登录、Cookie 或专用下载接口的网站可能返回 403，例如部分网盘链接；能在浏览器打开的页面地址不一定是文件直链。

## 今日人品

按电脑本地日期计算 0～100 的娱乐分数，同一天保持不变，不依赖登录或联网。

当天第一次点击时会从对应分数范围抽取一句文案，并保存到配置；之后点击或重启仍显示同一句。第二天第一次点击时重新抽取。

第一次使用要确认免责声明，以后不重复提醒。清理缓存不清除当天记录，重置配置会清除。修改系统日期也会影响结果。

## 清理游戏垃圾

点击就会开始，**没有确认弹窗，完成后自动重启 ELCL**。排查故障时请先备份需要的日志和崩溃报告。

| 会清理 | 会保留 |
| --- | --- |
| ELCL 缓存，包括皮肤、披风、版本清单和安装缓存。 | 配置、账户和匿名安装 ID。 |
| 旧日志，以及游戏和版本目录的 `logs`、`crash-reports`、`cache`、`.cache`、`server-resource-packs`。 | 存档、模组、截图、版本文件、共享支持库和资源。 |

有下载、安装或运行中的游戏时，需先结束任务。被占用、无权限的文件及链接目录会跳过，不会强制结束其他程序。

重启前后会清扫缓存，通知显示合计删除文件数和释放容量。之后按需重新生成头像、版本列表等缓存是正常现象。

## 内存优化

与 **设置 → 启动 → 内存分配** 中的按钮执行相同操作，结果通过通知条显示。

它整理 Windows 工作集，不等于 Java 垃圾回收，也不保证提升帧率。详见[内存优化](launch-settings.md#内存优化)。
