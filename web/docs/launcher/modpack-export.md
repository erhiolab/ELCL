# 导出整合包

打开 **版本设置 → 导出**。这个入口位于侧栏末尾，使用百宝箱图标。

## 导出一个版本

1. 等待页面扫描当前版本。名称默认是当前版本名，整合包版本默认是 `1.0.0`，都可以修改。
2. 在 **导出内容** 中勾选需要的分类。游戏本体必选，导入时按清单安装 Minecraft 与加载器，不复制当前客户端、支持库或资源库。
3. 需要微调时，展开 **精确选择文件**，在目录树中勾选具体文件或文件夹。可以按文件名、相对路径筛选。
4. 点击 **开始导出**，选择当前版本目录之外的保存位置，然后到任务列表查看进度。

默认生成 `.mrpack`，可以通过[导入整合包](modpacks.md)重新安装。导出过程中不要修改源版本文件；游戏正在保存、文件被占用或扫描后内容变化时，导出可能失败，需要重新扫描后重试。

当前版本已有运行、安装或其他文件处理任务时，请先结束或等待这些任务再导出。

## 默认选择什么

| 内容 | 默认状态 |
| --- | --- |
| 游戏版本与加载器清单 | 必选 |
| 游戏设置、启用的 Mods、`config/`、`defaultconfigs/`、`kubejs/`、`scripts/`、材质包和光影 | 选中 |
| 禁用的 Mods、存档、个人与服务器记录、截图、日志、缓存、其他未识别文件 | 不选 |
| 客户端与版本 JSON、共享资源、原生库、启动器配置和链接 | 列出但不可选择 |

分类旁的半选框表示只选择了其中一部分文件。分类与文件勾选后都可以再次点击取消，分类选择与文件树同步，筛选只改变显示，不会清除已经勾选的其他文件。

鼠标在文件树上时，滚轮优先滚动文件列表；列表不需要滚动或已到达对应边界时，继续滚动外层页面。

需要更新文件列表时，将鼠标移到侧栏 **导出** 上，点击右侧的刷新按钮。重新扫描会保留已有的选择路径，新出现的文件需要重新确认。

存档、服务器列表和自定义配置可能包含你自己的内容，分享前请检查所选文件。无法识别的文件会放在 **其他文件**，可以自行决定是否加入。

## 高级选项

**打包资源文件**：将选中的 Mods、材质包和光影直接放进整合包。关闭时，会尝试用文件摘要匹配准确的上游文件，并记录它的下载地址；没有匹配、网络查询失败或来源不提供可用下载地址时，仍打包本地文件。不会自动替换成其他版本。

**仅从 Modrinth 下载资源文件**：只查询 Modrinth。关闭时，也可以匹配 CurseForge；CurseForge 引用遵守其第三方下载许可。这项选择在直接打包资源时不生效。来源查询使用社区资源下载源设置，导出清单记录原始地址，导入时再应用下载源偏好。

这两个选项都不会把 Minecraft 与加载器变成离线安装包。它们仍由导入过程安装。

### 读取与导出配置

**导出配置**把包名、包版本、已选相对路径和导出选项保存为独立 JSON。下次扫描完版本后，点击 **读取配置** 即可复用，不需要自己编写规则。

配置中不存在于当前版本、或属于不可导出内容的路径会跳过，通知会显示数量。导出配置不包含文件内容，也不修改启动器的全局配置。

导出配置最多 8 MiB，保存前需要填写包名与版本。

## 附带 ELCL

勾选 **附带 ELCL 启动器** 后，输出改为外层 ZIP，包含：

- `Launcher/`：当前 ELCL 的程序及运行依赖。
- 一个 `.mrpack`：刚刚选择的整合包内容。

接收者解压 ZIP 后，打开 `Launcher/` 中的 ELCL，再选择其中的 `.mrpack` 导入。外层 ZIP 本身不是整合包导入文件。

不会复制 ELCL 的账户、全局设置、Java 列表、缓存和游戏文件夹；Java 运行环境也不随启动器复制。没有可分发的 ELCL 可执行文件时，取消这个选项即可单独导出整合包。

## 取消、失败与兼容性

导出任务可以取消。未完成的临时归档会删除，已有目标文件只在完整导出后替换；任务移除只清理本次导出缓存，不删除源版本或已经完成的整合包。失败原因保留在任务和日志中。

单个文件最多 8 GiB，所选文件合计最多 64 GiB，扫描与导出最多 99000 个文件条目，清单最多 8 MiB。不遍历链接，不通过配置规则访问版本目录之外的文件。

Minecraft、Forge、NeoForge、Fabric 和 Quilt 使用常见的 Modrinth 依赖名称。LiteLoader 与 OptiFine 使用 ELCL 能读取的扩展依赖名；其他启动器是否接受它们取决于对应实现。自定义启动组件、手工修改的客户端或不完整的父版本元数据，不能保证通过通用整合包还原。
