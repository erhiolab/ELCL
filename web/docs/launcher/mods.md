# 下载与管理模组

在 **下载 → 模组** 中查找模组，或者打开某个版本的 **版本设置 → Mods**，管理已经安装的文件。

模组需要匹配游戏版本和加载器。安装前先确认游戏装有 Forge、NeoForge、Fabric、Quilt 或 LiteLoader；只有 OptiFine 的版本不会显示 Mods 管理入口。

## 查找模组

1. 输入模组名，选择 **全部**、**CurseForge** 或 **Modrinth**。
2. 选择 Minecraft 版本，也可以直接输入完整版本号。第一项 **全部（也可自行输入）** 表示不限版本。
3. 选择版本后，加载器选择框会出现；选择 **全部** 时它会收起，版本框平滑扩展占满空位。还可以按类型缩小范围。
4. 选择排序方式，再点击 **搜索**。默认使用 **默认排序**，优先显示与名称相关的模组；选择 **下载量** 时，优先显示下载次数更多的模组。使用底部按钮翻页。

“全部”会同时查询两个平台。默认排序会保留各平台的相关性顺序，按名次交替显示两个来源的结果；下载量排序则将结果合并后按下载次数从高到低排列。下载量是各平台自己的统计；同一模组在两个平台发布时，可以分别出现在结果中。类型按两个平台的相近分类匹配，不同平台的分类范围可能稍有区别。

切换排序会从第一页重新查询，保留当前名称和筛选条件；翻页时继续使用所选排序。游戏版本和加载器筛选仍然有效，不支持当前版本的模组不会因为更改排序而出现。

结果使用紧凑的三行布局：名称与原名、类型标签与简介，以及加载器、下载量、更新时间和来源平台。内容较长时可以悬停查看。

部分来源暂时不可用时，仍会显示另一来源的结果，并说明缺少哪个来源。网络恢复后可以刷新。

中文界面默认开启 **设置 → 个性化 → 社区资源 → 模组汉化**。开启时，名称优先使用随程序打包的 MC 百科词条索引，按平台项目的 slug 匹配，常见模组无需逐项联网搜索就能显示中文名和百科地址。索引未覆盖的项目会再尝试查询百科页面；未能确认对应关系时保留原名。支持用索引中收录的中文名称查找，少见名称也可以改用英文搜索。

关闭汉化或使用非中文界面时，列表、详情和前置模组显示来源原名，本地模组保留来源或文件内的名称，也不会查询或使用已有的百科译名。此时搜索词直接传给所选平台，请使用平台收录的名称；这个设置不翻译模组正文或 Minecraft 游戏内容。

中文名称会先转换成对应的英文名，再查询所选平台；游戏版本、加载器和类型筛选仍然有效。例如，“机械动力”会按 `Create` 搜索，但只会显示符合当前筛选的项目。如果找不到模组本体，可以先将游戏版本和类型设为 **全部**，再确认它支持哪些版本；名称或简介中包含相同关键词的其他模组也可能出现在结果中。

## 查看详情

点击结果进入详情，可以查看原名、简介、来源和下载量，打开来源页面、复制名称。**MC 百科** 按钮只在中文界面显示；点击后打开对应词条，尚未找到可靠对应词条或已关闭模组汉化时，打开百科搜索页。

文件按“加载器＋游戏版本”放在独立的折叠卡片中，例如 **NeoForge 26.3**。同一分组包含正式版、测试版和预览版，文件行左侧用不同图标区分，下面的说明也会标明发布类型。点击整张卡片的标题展开，查看发布日期、发布类型、文件名与下载按钮；展开和收起都有缓动。文件区域共用一条滚动条，展开多个卡片也不需要来回切换滚动区域。长列表只绘制可见的文件行。

默认沿用当前选择的游戏版本与加载器。只选择游戏版本时，显示该版本下的所有加载器分组；继续选择加载器可以进一步筛选。选择 **全部（也可自行输入）** 查看其他游戏版本，同时收起加载器筛选。详情页按当前游戏版本与加载器筛选条件读取文件元数据，选择“全部”时才读取全部匹配版本，不需要点击“加载更多”。展开、收起卡片不会重新请求文件列表，也不会下载模组本身。加载期间会显示已取得的文件数量；可以切换筛选或返回，取消这次读取。完成完整列表读取后，进一步筛选会优先复用当前页面的数据。CurseForge 的接口最多提供前 10000 个文件。

同一个文件支持多个游戏版本或加载器时，会出现在相应的多个卡片中。下载会检查你展开的那张卡片所对应的游戏版本与加载器。

分组展开后会读取其中各文件声明的必需前置，显示在 **前置模组** 中；不同文件的前置可能不同。点击前置模组打开它的详情，选择合适的文件自行下载，返回后可以继续查看原模组。前置读取失败不会阻止下载当前模组，可以收起后重新展开重试。

作者未允许第三方下载，或没有提供文件下载地址时，下载按钮不可用。请通过 **来源页面** 查看作者提供的获取方式。

## 下载安装

点击文件右侧的下载按钮，再选择保存位置：

- 文件夹选择器默认打开当前版本的 `mods/`，不存在时自动创建。直接选择当前版本根目录时，仍会放进其中的 `mods/`。
- 选择其他文件夹时，文件直接保存在所选文件夹内；也可以自行选择某个版本的 `mods/`。
- 从版本的 Mods 页面点击 **下载模组**，会带上该版本的 Minecraft 版本、加载器和默认目录。

下载会创建[任务](tasks.md)，使用当前连接数、限速和社区资源来源设置下载，校验后才安装。**每次只下载你选中的文件，不会自动下载任何前置模组。** 请根据模组说明自行安装所需前置。

未限定版本或加载器时，会从所选文件的适用范围确定兼容环境，优先沿用匹配的当前版本；无法确定时会提示先选择版本与加载器。

已启用且 SHA-1 相同的文件可以复用。同名文件或已禁用的同名文件会阻止安装，不会覆盖；请先确认是否已经安装了需要的版本。ELCL 不会自动替你替换旧版模组，安装另一个版本前应自行处理重复项。

取消或下载失败后，可以在任务列表移除任务，清理本次未完成的临时文件。已经存在的模组不会因此被删除。

## 管理当前版本的模组

Mods 页面只管理当前版本目录下的 `mods/`，不影响其他版本。

打开页面后会先列出所有模组文件，再逐项补充名称、版本、标签和图标。显示“正在读取详情”的文件尚未解析完成，稍后会在原位置更新，不会重建整份列表。此时仍可选择文件、打开所在位置、启用、禁用或删除；详情按钮在文件解析后可用。

来源识别与百科译名在后台补充，不会挡住其他文件的本地信息。刷新、切换版本或离开页面时，会停止本次尚未完成的列表读取。某个文件损坏时只标记该文件，不影响其余条目。

列表使用与下载页一致的紧凑信息布局：上方显示名称、可用的原名和本地模组版本，下方显示分类、加载器、文件名与简介。禁用或异常文件会额外标注状态。分类和来源简介在识别来源后补充，离线时优先使用已有缓存与文件内的信息。长内容可以悬停查看；搜索支持名称、原名、文件名、版本、简介与标签。

可以一次拖入多个 `.jar` 或 `.litemod` 文件，放到 Mods 页面的文件列表、空白区域或搜索框上均可；也可以点击 **从文件安装**，在选择文件时多选。同名冲突时不会覆盖现有文件；导入多个文件时会先检查名称。支持一并导入已禁用的模组。文件夹和其他类型的文件不接受拖入，请只选择模组文件。

这两种方式都只在添加成功后显示一次通知，告知实际添加了多少个模组。添加失败时显示错误通知，不会提示添加成功；修改后需要重新启动游戏才能生效。

以管理员权限运行 ELCL 时，Mods 页面会临时将窗口切换为 Windows 文件拖放接收，兼容从普通权限的资源管理器拖入文件。离开页面后恢复原来的拖放方式，处理文件期间暂不接受新的拖入；此通道一次最多接收 4096 个文件。接收失败或拖入不支持的文件时，会显示错误通知并记录日志。

拖放以文件放下的位置为准，放在当前 Mods 页面内才会导入；标题栏、侧栏和其他页面不会安装模组。如果出现有拖放光标却未添加文件的情况，可以在日志的 `DragDrop` 和 `Mods` 记录中查看文件是否被接收，以及忽略或导入失败的原因。

鼠标悬停在模组上，会显示四个操作：

| 操作 | 效果 |
| --- | --- |
| 详情 | 尝试识别来源，打开对应的模组详情；没有找到时显示本地文件信息。 |
| 在文件夹中显示 | 打开资源管理器并选中这个文件。 |
| 禁用／启用 | 保留文件，通过扩展名切换启用状态。 |
| 删除 | 确认后永久删除这个文件。 |

按住 Ctrl 或 Shift 多选，页面底部会出现批量启用、禁用、删除和取消选择。**全选** 选择当前筛选后的列表。

名称和图标优先从模组文件中读取，支持 NeoForge 的 `iconFile`、Forge 的 `logoFile`，以及只在 Manifest 中提供名称与版本的库文件。缺少图标或可靠名称时，会尝试按文件指纹查询来源，补充项目名称、百科译名和图标；结果按文件内容缓存，重新打开无需重复识别。未收录或网络不可用时保留本地名称与默认图标。

无法解析的归档仍显示在列表中，使用错误图标并提供错误提示。可以定位、禁用或删除，避免坏文件藏在目录里。

修改文件后，需要重新启动游戏才能生效。这里不提供模组更新检查；游戏正在运行时，Windows 也可能拒绝修改它正在使用的文件。

## 下载源、文件名与列表样式

在 **设置 → 下载 → 下载源** 中，**社区资源下载源** 独立于游戏文件来源。支持官方优先或 MCIM 镜像优先，请求或文件下载失败时尝试另一来源。镜像可用性取决于第三方服务；没有镜像规则的地址保持原地址。

将鼠标悬停在 **社区资源下载源** 的名称或下拉框上，可以查看来源回退说明。

在 **设置 → 下载 → 社区资源** 中，可以选择 **模组文件名格式**：原始文件名，或用中文括号、方括号、前缀、后缀加入百科译名。默认保留原始文件名；没有可靠译名时也保留原名。只有中文界面且模组汉化开启时，此选项才可用；关闭汉化或切换到其他语言后，暂时使用原始文件名，保留之前选择的格式，重新启用汉化后恢复。已下载的文件不会自动改名。加入译名后过长的名称会缩短，扩展名不会改变，手动导入的文件不会被改名。

在 **设置 → 个性化 → 社区资源** 中，可以选择 **模组列表样式**：名称优先时，上方显示模组名称与原名，下方显示文件名和简介；文件名优先时，上方改为文件名，下方显示模组名称和简介。两种样式都保留版本号、分类、加载器和状态标签。重新进入或刷新 Mods 页面后应用。

这些选项会保存在全局配置中，随配置导入／导出。重置下载设置会恢复官方优先和原始文件名；重置个性化设置会开启模组汉化并恢复名称优先的列表样式。

图标与译名缓存位于 `ELCL/cache/community/`。成功译名保留七天，确认未找到的结果只保留十分钟；网络失败或百科限流不会保存为长期未收录结果。旧版空结果缓存不再使用。清理缓存后会按需重新获取；本地模组文件不会被缓存清理删除。重要操作及失败原因记录在 `ELCL/logs/`。

中文名称与百科地址来自随程序发布的词条快照。来源与署名见核心附带的 `ThirdParty/MCMod-Index-NOTICE.md`。数据随 ELCL 更新，不代表百科的实时完整收录。
