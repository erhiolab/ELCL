# 获取社区资源

打开 **下载 → 社区资源**，可以在 Mods、整合包、数据包、资源包和光影包五个栏目中搜索 CurseForge 和 Modrinth。要启用、禁用或移除已经安装的 Mods，请看[管理当前版本的 Mods](#管理当前版本的-mods)。

## 查找与筛选 {#查找-mods}

1. 先在侧栏选资源类别，输入名称。留空可以直接浏览。
2. 按来源、游戏版本和类型筛选。版本可手动输入；第一项 **全部（也可自行输入）** 表示不限版本。查找 Mods 或整合包时，选定游戏版本后还可以按加载器筛选。
3. 选择排序方式，点击 **搜索**。**默认排序** 优先显示名称相关的项目，**下载量** 优先显示下载次数更多的项目。用底部按钮翻页。

每个栏目单独保留筛选。点击 **重置条件** 会清空名称和筛选，恢复默认排序并重新读取第一页，不会更改安装目标。侧栏当前栏目右侧的刷新按钮则保留筛选，只重新查询第一页。

选择 **全部** 来源时，同一项目在两个平台发布可以分别出现，分类也可能有所不同。如果某个平台暂时不可用，页面会保留另一平台的结果，并提示缺少哪个来源。当前页显示后会在后台准备下一页，翻页时从列表顶部开始。

### 用中文名称查找 Mods

中文界面默认开启 **设置 → 个性化 → 社区资源 → Mods 汉化**。开启时，名称优先使用随程序打包的 MC 百科词条索引，按平台项目的 slug 匹配，常见 Mods 无需逐项联网搜索就能显示中文名和百科地址。索引未覆盖的项目会再尝试查询百科页面；未能确认对应关系时保留原名。支持用索引中收录的中文名称查找，少见名称也可以改用英文搜索。

关闭汉化或使用非中文界面时，列表、详情和前置 Mods 显示来源原名，本地 Mods 保留来源或文件内的名称，也不会查询或使用已有的百科译名。此时搜索词直接传给所选平台，请使用平台收录的名称；这个设置不翻译 Mods 正文或 Minecraft 游戏内容。

中文名称会先转换成对应的英文名，再查询所选平台；游戏版本、加载器和类型筛选仍然有效。例如，“机械动力”会按 `Create` 搜索，但只会显示符合当前筛选的项目。如果找不到 Mods 本体，可以先将游戏版本和类型设为 **全部**，再确认它支持哪些版本；名称或简介中包含相同关键词的其他 Mods 也可能出现在结果中。

## 查看详情

点击项目进入详情，可以查看名称、简介、来源和下载量，也可以打开来源页面或复制名称。中文界面的 Mods 详情提供 **MC 百科** 按钮：有对应词条时打开词条，否则打开百科搜索。

文件按游戏版本分组；Mods 和整合包还会按加载器细分，例如 **NeoForge 26.3**。展开卡片后可以看发布日期、文件名和发布类型，正式版、测试版和预览版会放在同一组。同一个文件支持多个版本时，可以出现在多个分组。

详情页沿用搜索时的版本筛选条件，也可以在上方切换。切换到 **全部（也可自行输入）** 可以查看更多版本；CurseForge 最多返回前 10000 个文件。如果下载按钮不可用，可以点击 **来源页面** 查看作者提供的获取方式。

## 下载 Mods {#下载安装}

Mods 需要与游戏版本和加载器匹配。展开文件所在分组，可以看到该组文件声明的 **前置 Mods**；不同文件的前置可能不同。点击前置项目可打开它的详情，自行下载后再返回。前置读取失败时，可以收起分组再展开重试，不影响下载当前文件。

点击文件右侧的下载按钮，再选择保存位置：

- 文件夹选择器默认打开当前版本的 `mods/`，不存在时自动创建。直接选择当前版本根目录时，仍会放进其中的 `mods/`。
- 选择其他文件夹时，文件直接保存在所选文件夹内；也可以自行选择某个版本的 `mods/`。
- 从版本的 Mods 页面点击 **下载 Mods**，会带上该版本的 Minecraft 版本、加载器和默认目录。

下载会创建[任务](tasks.md)，使用当前连接数、限速和社区资源来源设置下载，校验后才安装。**每次只下载你选中的文件，不会自动下载任何前置 Mods。** 请根据 Mods 说明自行安装所需前置。

未限定版本或加载器时，会从所选文件的适用范围确定兼容环境，优先沿用匹配的当前版本；无法确定时会提示先选择版本与加载器。

已启用且 SHA-1 相同的文件可以复用。同名文件或已禁用的同名文件会阻止安装，不会覆盖；请先确认是否已经安装了需要的版本。ELCL 不会自动替你替换旧版 Mods，安装另一个版本前应自行处理重复项。

取消或下载失败后，可以在任务列表移除任务，清理本次未完成的临时文件。已经存在的 Mods 不会因此被删除。

## 下载或安装整合包

对整合包文件点击 **下载** 后，可选择以下操作：

| 选项 | 会发生什么 |
| --- | --- |
| **下载文件** | 选择保存位置，只保存原始 ZIP 或 MRPACK，不安装游戏。可以稍后从[版本选择](versions.md)导入。 |
| **安装到当前版本目录** | 输入新版本的名称，ELCL 会在当前游戏目录的 `versions` 下新建一个独立版本，按整合包清单安装游戏、加载器和包内内容。不会覆盖当前选中的版本。 |

两个弹窗显示的是「版本选择」里的游戏文件夹名称，包括你自定义的名称。选择安装时，使用与[从文件导入整合包](modpacks.md#从按钮导入)相同的命名弹窗。要换安装位置，先回到「版本选择」切换游戏文件夹；新版本名称已被占用时，需要换一个名字。安装失败或取消后，不会删除已有版本。支持的清单格式与本地导入相同。

## 保存数据包、资源包和光影包

| 资源 | 游戏读取的位置 |
| --- | --- |
| 数据包 | 世界存档下的 `datapacks`。选择包含 `level.dat` 的世界目录时，ELCL 会把 ZIP 放入其 `datapacks`。 |
| 资源包 | 游戏版本目录下的 `resourcepacks`。 |
| 光影包 | 游戏版本目录下的 `shaderpacks`。还需要在游戏中安装并启用兼容的光影支持。 |

如果选择了游戏版本，文件夹选择器优先打开相应目录；选择该版本根目录时，资源包和光影包会自动存入上表对应的子目录。也可以存到其他目录留待以后使用。

不会覆盖同名文件。可在[任务管理](tasks.md)查看进度或取消下载。

也可以从[版本设置](version-settings.md#管理资源包和光影包)直接进入资源包或光影包下载列表，自动带上该版本的 Minecraft 版本。已经安装的包可在那里查询来源、启用或禁用。

## 管理当前版本的 Mods

打开 **版本设置 → Mods**，这里仅管理当前版本目录下的 `mods/`，不影响其他版本。安装了 Forge、NeoForge、Fabric、Quilt 或 LiteLoader 的版本会显示入口；只有 OptiFine 的版本不会显示。

打开页面后会先列出所有 Mods 文件，再逐项补充名称、版本、标签和图标。显示“正在读取详情”的文件尚未解析完成，稍后会在原位置更新，不会重建整份列表。此时仍可选择文件、打开所在位置、启用、禁用或删除；详情按钮在文件解析后可用。

来源识别与百科译名在后台补充，不会挡住其他文件的本地信息。要重新扫描，将鼠标移到左侧 **Mods**，点击右侧的刷新图标。切换版本或离开页面时会收起本地信息，并停止尚未完成的列表读取。某个文件损坏时只标记该文件，不影响其余条目。

列表使用与下载页一致的紧凑信息布局：上方显示名称、可用的原名和本地 Mods 版本，下方显示分类、加载器、文件名与简介。禁用或异常文件会额外标注状态。分类和来源简介在识别来源后补充，离线时优先使用已有缓存与文件内的信息。长内容可以悬停查看；搜索支持名称、原名、文件名、版本、简介与标签。

可以一次拖入多个 `.jar` 或 `.litemod` 文件，打开 Mods 页面后，放到启动器左侧栏、文件列表或空白区域均可；也可以点击 **从文件安装**，在选择文件时多选。同名冲突时不会覆盖现有文件；导入多个文件时会先检查名称。支持一并导入已禁用的 Mods。文件夹和其他类型的文件不接受拖入，请只选择 Mods 文件。

这两种方式都只在添加成功后显示一次通知，告知实际添加了多少个 Mods。添加失败时显示错误通知，不会提示添加成功；修改后需要重新启动游戏才能生效。

以管理员权限运行 ELCL 时，会使用 Windows 文件拖放接收来自普通权限资源管理器的文件。一次最多接收 4096 个文件，处理期间暂不接受新的拖入。

拖入的文件交给当前打开的页面。弹窗、账号管理或任务管理打开时，不会把文件安装到底下的 Mods 页面。可以在日志的 `DragDrop` 和 `Mods` 分类查看接收和导入结果。

鼠标悬停在 Mods 上，会显示四个操作：

| 操作 | 效果 |
| --- | --- |
| 详情 | 打开对应的在线详情。找不到来源或查询失败时，会提示并自动展开 **本地信息**。 |
| 在文件夹中显示 | 打开资源管理器并选中这个文件。 |
| 禁用／启用 | 保留文件，通过扩展名切换启用状态。 |
| 删除 | 确认后永久删除这个文件。 |

选中一个 Mod 后，也可以直接点列表下方的 **本地信息**，离线查看文件内的描述、版本、Mod ID、加载器和读取错误。

按住 Ctrl 或 Shift 多选，页面底部会出现批量启用、禁用、删除和取消选择。**全选** 选择当前筛选后的列表。

名称和图标优先从 Mods 文件中读取，支持 NeoForge 的 `iconFile`、Forge 的 `logoFile`，以及只在 Manifest 中提供名称与版本的库文件。缺少图标或可靠名称时，会尝试按文件指纹查询来源，补充项目名称、百科译名和图标；结果按文件内容缓存，重新打开无需重复识别。未收录或网络不可用时保留本地名称与默认图标。

无法解析的归档仍显示在列表中，使用错误图标并提供错误提示。可以定位、禁用或删除，避免坏文件藏在目录里。

修改文件后，需要重新启动游戏才能生效。这里不提供 Mods 更新检查；游戏正在运行时，Windows 也可能拒绝修改它正在使用的文件。

## 下载源、文件名与列表样式

在 **设置 → 下载 → 下载源** 中，**社区资源下载源** 独立于游戏文件来源。支持官方优先或 MCIM 镜像优先，请求或文件下载失败时尝试另一来源。镜像可用性取决于第三方服务；没有镜像规则的地址保持原地址。

将鼠标悬停在 **社区资源下载源** 的名称或下拉框上，可以查看来源回退说明。

在 **设置 → 下载 → 社区资源** 中，可以选择 **Mods 文件名格式**：原始文件名，或用中文括号、方括号、前缀、后缀加入百科译名。默认保留原始文件名；没有可靠译名时也保留原名。只有中文界面且 Mods 汉化开启时，此选项才可用；关闭汉化或切换到其他语言后，暂时使用原始文件名，保留之前选择的格式，重新启用汉化后恢复。已下载的文件不会自动改名。加入译名后过长的名称会缩短，扩展名不会改变，手动导入的文件不会被改名。

在 **设置 → 个性化 → 社区资源** 中，可以选择 **Mods 列表样式**：名称优先时，上方显示 Mods 名称与原名，下方显示文件名和简介；文件名优先时，上方改为文件名，下方显示 Mods 名称和简介。两种样式都保留版本号、分类、加载器和状态标签。重新进入或刷新 Mods 页面后应用。

这些选项会保存在全局配置中，随配置导入／导出。重置下载设置会恢复官方优先和原始文件名；重置个性化设置会开启 Mods 汉化并恢复名称优先的列表样式。

图标与译名缓存位于 `ELCL/cache/community/`。成功译名保留七天，确认未找到的结果只保留十分钟；网络失败或百科限流不会保存为长期未收录结果。旧版空结果缓存不再使用。清理缓存后会按需重新获取；本地 Mods 文件不会被缓存清理删除。重要操作及失败原因记录在 `ELCL/logs/`。

图标在后台解码并缩放为 64 × 64 的 PNG 缓存，已有缓存可以继续使用。支持 PNG、JPEG、GIF、BMP、TIFF、ICO 和 WebP；动画图标仅显示首帧。输入超过 4 MiB、像素总数超过 16777216 或数据损坏时不显示该图标，保留默认图标。普通格式使用 Windows 图像编解码器，WebP 使用随程序内置的专用解码器，无需另装 WebP 扩展。

中文名称与百科地址来自随程序发布的词条快照。来源与署名见核心附带的 `ThirdParty/MCMod-Index-NOTICE.md`。数据随 ELCL 更新，不代表百科的实时完整收录。
