# 皮肤与披风

在账号管理中选择 Microsoft 账户，下方会展开外观区域。离线用户没有这个区域。

## 头像与缓存

ELCL 读取账户当前的皮肤，再生成启动页和账号列表中的头像。皮肤和披风图片缓存到 `ELCL/cache/skins/`，包括披风列表所需的缩略图。

加载图片是后台操作，不会每张图片都发一条通知。网络失败时可在日志中查看原因；清理缓存后，需要重新获取图片。

## 查看三维模型

- 按住鼠标左键拖动，旋转模型。
- 滚动滚轮，拉近或拉远。
- 点击预览右上角的复位图标，恢复默认角度和距离。
- 停止操作约 3 秒后，模型会自动旋转；再次操作会停止并重新计时。

切换 **鞘翅预览** 可以查看披风对应的鞘翅效果。这只是本地预览，不会给游戏中的角色装备物品。

## 上传皮肤

点击 **上传皮肤**，选择 Minecraft 皮肤 PNG。ELCL 会检查图片，再将它上传到当前 Microsoft 账户。

上传会修改账户的实际皮肤，不只是更换本地预览。主动操作的进度、完成或失败会通过通知条显示。

## 修改模型

选择普通手臂或纤细手臂模型，再点击应用。修改模型会使用当前皮肤重新上传，因此需要有效的登录状态和网络连接。

## 切换披风

披风列表用缩略图显示这个账户拥有的样式。选中后可以预览，点击应用才会提交到账户；选择不使用披风则取消装备。

ELCL 只能切换账户已经拥有的披风，不能上传任意图片作为官方披风。应用成功后会刷新当前状态。
