# 关于与许可

打开 **更多 → 关于**，可以查看 ELCL 与 ELCLC 的版本、项目仓库和鸣谢。

## 查看法律信息

在 **许可与版权声明** 上方，展开默认收起的 **法律信息** 卡片，即可查看项目声明、统计开关的位置，并在浏览器打开[用户协议](terms.md)、[分发许可](distribution-license.md)、[隐私说明](privacy.md)和源代码。相关页面也收录于 [ELCL 法律声明](legal.md)。

## 查看许可与版权声明

页面底部的 **许可与版权声明** 卡片默认收起，点击标题栏可以展开或收起。展开后可查看启动器使用的组件、参考项目、资料和在线服务，按用途分组：

| 分组                     | 内容                                                                   |
| ------------------------ | ---------------------------------------------------------------------- |
| 应用与基础组件           | ELCL、ELCLC、.NET、WPF，以及图片处理组件与第三方声明。                 |
| 启动补丁、参考项目与标识 | Java 启动兼容补丁、PCL、Prism Launcher、HMCL，以及鸣谢页的图标与头像。 |
| 资料与百科资源           | MC 百科的译名与词条映射、Minecraft Wiki 的资料。                       |
| 在线服务与下载来源       | 账户登录、游戏与社区资源下载、镜像、Java 发行平台和匿名统计服务。      |

每个条目都有两个按钮：

- **查看来源**：在浏览器中打开项目仓库或官方网站。
- **查看许可**：在浏览器中打开该项目的许可、版权声明或服务说明。在线服务的条款与软件源代码许可用途不同，请以链接中的原文为准。

这些链接需要网络连接。许可清单和鸣谢图标随启动器提供，打开关于页本身不会请求这些网站。

## 下载内容的许可

Minecraft、Java、加载器和 Mods 由用户另行下载安装，各自遵循对应版本附带的许可与使用条款。关于页列出的服务来源不代替这些文件自身的声明。
