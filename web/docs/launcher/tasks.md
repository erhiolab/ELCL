# 任务管理

有活动任务或待处理的失败任务时，窗口右下角会出现任务列表入口。打开后可以查看每项任务的阶段、文件进度和操作按钮。

## 哪些操作会创建任务

- 安装原版或模组加载器。
- 下载自定义文件。
- 启动游戏，以及窗口出现后的运行记录。
- 补全游戏文件、重命名或删除版本等版本管理操作。

一个安装任务可以包含大量文件，也可以包含需要运行 Java 的安装步骤。

## 怎么看进度

下载按收到的字节统计，不是每完成一个步骤就固定增加一截。文件总大小未知时，部分阶段无法给出准确百分比。

多文件下载可以同时进行，大文件也会在服务器支持时分段下载。处理器进度表示安装步骤完成比例，不能和下载字节数直接比较；游戏运行记录本身没有下载进度。

## 取消任务

点击取消会停止这个任务的后续操作。安装和启动任务还会结束本次创建、仍在运行的相关进程。

已经校验完成的共享支持库和资源通常会保留，方便下次使用。取消不会回滚所有已经完成的文件操作。

## 移除失败任务

失败会显示在对应任务里，不会立即把你带离任务页。确认原因后可以移除任务。

移除未完成的游戏安装任务，会清理本次创建的未完成版本和专用工作目录，不会删除整个游戏根目录。已有共享文件和其他版本保留。

## 完成后会发生什么

成功完成的任务自动移除。列表没有其他任务时，自动返回之前的页面，右下角入口也会隐藏。

## 终止运行中的游戏

运行任务显示游戏名称和进程 ID。**终止**只针对这个实例及其子进程，不会按 `java.exe` 的名字批量结束其他 Java 程序。

主动终止不算崩溃。异常退出则会保留错误信息和日志位置，便于排查。
