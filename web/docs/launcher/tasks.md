# 任务管理

有活动任务或待处理的失败任务时，窗口右下角会出现任务列表入口。打开后可以查看每项任务的阶段、文件进度和操作按钮。

## 哪些操作会创建任务

- 安装原版或模组加载器。
- 下载自定义文件。
- 启动游戏，以及窗口出现后的运行记录。
- 补全游戏文件、重命名或删除版本等版本管理操作。

一个安装任务可以包含大量文件，也可以包含需要运行 Java 的安装步骤。

## 怎么看进度

下载按收到的字节统计，不是每完成一个步骤就固定增加一截。文件总大小未知时，部分阶段无法给出准确百分比。

下载速度按所选的二进制或十进制自动换算，达到阈值后可以显示 GiB/s、GB/s 或更大的单位。

多文件下载可以同时进行，大文件也会在服务器支持时分段下载。处理器进度表示安装步骤完成比例，不能和下载字节数直接比较；游戏运行记录本身没有下载进度。

## 取消任务

点击取消会停止这个任务的后续操作。安装和启动任务还会结束本次创建、仍在运行的相关进程。

已经校验完成的共享支持库和资源通常会保留，方便下次使用。取消不会回滚所有已经完成的文件操作。

## 移除失败任务

失败会显示在对应任务里，不会立即把你带离任务页。确认原因后可以移除任务。

移除未完成的游戏安装任务，会清理本次创建的未完成版本和专用工作目录，不会删除整个游戏根目录。已有共享文件和其他版本保留。

## 完成后会发生什么

成功完成的任务自动移除。列表没有其他任务时，自动返回之前的页面，右下角入口也会隐藏。正在查看游戏日志时会保留日志页，返回任务列表后再退出任务管理。

## 查看实时 Minecraft 日志

游戏窗口出现后，运行任务旁会显示 **日志** 按钮。点击后查看这个进程的输出，顶部显示游戏名称、PID 和运行状态；返回按钮回到任务列表。

每次启动都有独立的日志文件。同一版本同时开多个实例时，各任务只打开自己对应的日志，不会混在一起。游戏退出后，已经打开的日志页会保留最后的输出；异常退出留下的任务也仍可打开日志。

- **保持更新**：持续读取新输出。取消勾选只暂停页面更新，文件仍正常记录。
- **自动滚动**：新内容出现时滚到末尾。向上滚动查看旧内容时会暂停跟随，手动滚回底部或点击 **回到末尾** 恢复。
- **自动换行、彩色输出**：长路径和异常堆栈也会按可视宽度换行；级别用颜色区分，消息正文保持统一颜色，方便连续阅读。
- **级别筛选**：可以查看全部日志、警告和错误，或仅错误；上方同时显示保留内容中的警告与错误数量。
- **原始文本**：在整理后的日志和原始记录之间切换。
- **查找下一处**：在当前筛选结果中循环搜索，不区分大小写，也可以按 Enter。原始文本模式下搜索原文。
- **复制**：有选中条目时复制选中内容，否则复制当前筛选结果，也支持 Ctrl＋C。原始文本模式下复制原文。
- **清空显示**：清除当前页面的内容，之后继续接收新输出，不删除或截断日志文件。
- **打开日志文件**：用记事本查看完整文件。

为了避免大量输出拖慢界面，页面最多保留最近 10000 条，并限制显示缓存。打开较大的文件或积压输出过多时，从文件尾部约 1 MiB 开始读取，特别长的行会分段显示。完整内容保存在 `ELCL/logs/game/`，显示限制不会影响文件记录。

### 为什么原始文件里有 XML

部分 Minecraft 版本的启动日志配置使用 Log4j XML 输出，这种格式便于启动器读取级别、线程和消息。ELCL 会把一个事件的消息与异常堆栈合并，分别显示时间、级别、线程和正文，不在普通视图中显示 XML 标签或重复的采集时间。

将鼠标移到线程或消息上可以查看完整线程名与日志来源。需要检查 Log4j 属性、CDATA 或采集顺序时，勾选 **原始文本**，或打开完整文件；磁盘上的原始内容会保留。无法解析的片段仍以文本显示，避免丢失排错信息。

日志使用现有的令牌脱敏结果。复制和打开文件都不会上传内容。

## 终止运行中的游戏

运行任务显示游戏名称和进程 ID。**终止**只针对这个实例及其子进程，不会按 `java.exe` 的名字批量结束其他 Java 程序。

主动终止不算崩溃。异常退出则会保留错误信息和日志位置，便于排查。
