# 隐私与匿名统计

入口：**设置 → 其他 → 隐私**。可以关闭 **允许匿名数据收集**，此选项默认开启。

关闭会取消尚未完成的统计请求，并阻止之后上报。已经发出的事件无法通过本地开关撤回；重新开启也不会补报关闭期间的事件。

## 发送哪些事件

当前通过 HTTPS 向 PostHog 美国区发送两类事件：

| 事件 | 触发时机 |
| --- | --- |
| `launcher_opened` | 每个 ELCL 进程启动时最多尝试一次。 |
| `game_launch_succeeded` | 确认游戏可见窗口首次出现后，每次成功启动尝试一次。 |

事件带有随机安装 ID 和 UTC 时间。仅导出脚本、只创建进程或窗口出现前失败，都不会算作游戏启动成功。

不上传账户、玩家名、UUID、令牌、游戏版本、加载器、路径、进程 ID、机器码或硬件信息。没有自动会话录制，也不将安装 ID 关联到账户。

## 安装 ID

随机 UUID 保存在 `ELCL/installation-id`，与配置和账户分开，不包含在配置导出或缓存清理中。

删除后会生成新 ID；复制整个数据目录可能同时复制它。因此它用于区分安装，不是严格区分人数或物理电脑。

## 网络与失败处理

统计在后台发送，不阻塞游戏启动。离线或发送失败时不重试、不保存待上报队列；配置或安装 ID 无法读取时会跳过相应事件。

事件正文不主动携带 IP，并请求关闭 IP 和地理位置补全。网络服务仍能看到建立连接时的出口 IP，不能理解为连接本身完全匿名。

## 账户和外观数据

账户与 Microsoft 令牌保存在本地 `ELCL/accounts.json`，令牌通过 Windows 当前用户的数据保护机制保存。登录、验证、上传皮肤和切换披风会访问相应的 Microsoft、Xbox 或 Minecraft 服务。

皮肤和披风图片缓存在 `ELCL/cache/skins/`。清理垃圾会删除这些图片，但不会删除账户记录。

## 本地机器码

本地机器码方法与匿名统计分开。它基于 Windows 安装标识生成应用专用的 SHA-256 值，不上传原始标识，也不用作 PostHog 的安装 ID。

重新安装或克隆 Windows 可能改变其稳定性或唯一性。
