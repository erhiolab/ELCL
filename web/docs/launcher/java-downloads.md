# 下载 Java

打开 **下载 → Java**，选择发行平台、Java 主版本，再从下面选一个具体版本。

ELCL 会按当前设备筛选下载。可选 Mojang、Adoptium Temurin、Azul Zulu 和 IBM Semeru Open；**刷新全部平台** 会同时更新四家的目录，侧栏 Java 右侧的双箭头也可以刷新。

## 选择哪个包

运行游戏一般选择 **JRE** 即可。**JDK** 包含开发工具和运行环境，也可以启动游戏，但下载与占用空间通常更大。

主版本要符合游戏的要求。安装 Java 本身不会改变某个 Minecraft 版本的兼容范围，最终由[启动设置中的 Java 列表](launch-settings.md)决定使用顺序。

列表显示版本、类型、架构和上游提供的日期、大小。ZIP 中保存完整运行时；Mojang 的“文件清单”会逐个下载需要的文件，安装后的用法相同。上游没有提供的日期或大小不会编造显示。

需要更早的版本时点击 **加载更多版本**。部分平台没有为某些系统或架构提供发行包，遇到空列表可以换一个主版本或平台。

## 安装到哪里

1. 选中一个版本，点击 **下载并安装**。
2. 在文件夹选择器中选择安装位置。ELCL 会在其中创建这个 Java 的独立文件夹。
3. 到任务列表查看下载、校验、解压和验证进度，也可以在那里取消。
4. 验证成功后，Java 路径自动保存到 **设置 → 启动 → Java**，安装完成。

同名安装目录已存在时会停止并提示更换位置，避免覆盖已有 Java。新 Java 加到列表末尾，保留原来的优先顺序；需要优先使用它时，可以在设置中向上移动，或在[版本独立设置](version-settings.md#选择-java)中指定。

## 删除由 ELCL 安装的 Java

在 **设置 → 启动 → Java** 中，由启动器下载的项目会标注 **ELCL 安装**。鼠标移到该行，点击垃圾桶按钮，确认后删除整个 Java 安装目录和列表项；确认框会列出实际目录。请先结束正在使用它的游戏或安装任务。

旁边的叉号仍然只是 **从列表移除**，不会删除文件。扫描发现或普通手动添加的 Java 不提供删除安装按钮。

配置中的每个 Java 项目分别保存 `InstalledByLauncher`、`InstallationDirectory` 和 `InstallationId`。安装目录内的 `.elcl-java.json` 用于核对归属，刷新列表会保留这些信息；不要单独移除这个标识文件。移除后再次手动添加同一个 Java，可通过目录标识恢复“ELCL 安装”状态。

旧配置没有这些字段时，按普通 Java 处理。重置启动设置不会删除已安装的 Java，ELCL 安装的项目会重新验证并保留来源。整个配置被清空后，自定义位置中的 Java 可能需要重新手动添加。

安装通过直接解压或下载文件完成，不运行系统安装向导，不修改 `JAVA_HOME` 或系统 PATH。解压后会实际运行 Java，检查能否启动、主版本及位数是否相符，通过后才登记到配置。

## 下载与校验

Java 安装使用现有的多线程下载任务，遵守 **设置 → 下载** 中的最大连接数与限速。ZIP 支持时分段下载，Mojang 的文件清单则可以并发下载多个文件。

压缩包会检查上游的 SHA-256；Mojang 清单及文件使用 SHA-1。校验失败不会继续执行下载的 Java。

如果发行方标注的大小或校验值与实际下载内容不一致，任务同样会停止。可以先刷新目录；仍失败时尝试其他版本或发行平台。

Java 数据直接来自各发行方，当前不套用 Minecraft 文件下载源的镜像规则。一个平台刷新失败时仍可使用其他平台，网络恢复后可以再刷新。

## 失败或取消

任务会保留错误和移除入口。移除未完成任务会清理本次安装的临时内容及尚未登记的安装目录，保留选定位置内的其他文件。完成后的临时下载与解压目录会清理，已经验证并登记的 Java 不会因移除任务而删除。

若强制结束启动器，安装位置中可能留下 `.elcl-java-` 开头的临时目录。排错时先查看 `ELCL/logs/Log1.txt` 中的 Java 与 Tasks 记录。
