# ELCL 分发有限许可

此页面说明分发 ELCL 时的授权范围，不是替代许可证。ELCL 和 ELCLC 以仓库中的 [GNU GPL v3](https://github.com/ErhioLab/ELCL/blob/main/LICENSE) 为准，本页不对 GPL 已授予的权利增加条件。

## 分享程序与修改版本

你可以按 GPLv3 的条件复制、镜像或分发原版，也可以修改并分发自己的版本。请保留适用的版权和许可声明；分发二进制时，按 GPLv3 要求提供其对应源代码；分发修改版本时，按许可证要求标明修改。是否收费不改变这些义务，本页不禁止 GPLv3 所允许的收费分发。

## 标识和第三方内容

软件版权许可不授予以 ErhioLab、Mojang 或 Microsoft 的名义背书、发布或运营的权利。分享他人构建的版本时，应清楚区分其来源，不把第三方构建称为 ErhioLab 或 Minecraft 的官方发布。

Minecraft 客户端、账户服务、下载的 Mods、整合包以及第三方标识不因与 ELCL 一同使用而取得新的分发许可。分享它们时，应分别核对权利人的许可；如只分享启动器，应区分启动器文件与后续下载的内容。

具体许可和第三方来源见[关于与许可](about.md)。对软件授权条款有疑问时，请以 [GPLv3 原文](https://www.gnu.org/licenses/gpl-3.0.html)为准。
