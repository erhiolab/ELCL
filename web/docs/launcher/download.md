# 下载与安装

打开 **下载**，选择 Minecraft 版本，再在详情页确认安装名称和加载器，点击 **开始下载**。

## 查找 Minecraft 版本

版本按正式版、预览版、远古版和愚人节版本分类，可搜索版本号。详情页提供版本信息与 Wiki 内容。

版本列表有本地缓存：打开启动器先显示缓存，再在后台检查更新。缓存不可用时需要联网获取。Wiki 读取失败不会改变游戏版本本身的下载信息。

## 选择模组加载器

支持 Forge、NeoForge、Fabric、Quilt、LiteLoader 和 OptiFine。不是每个 Minecraft 版本都提供全部加载器，没有结果通常表示不支持该游戏版本。

加载器通常不能混装。选择冲突项时会调整已有选择；目前仅允许元数据明确兼容的 Forge 与 OptiFine 组合。

安装加载器不等于安装模组。Fabric API、Quilt 的模组 API 和其他模组仍需自行放入版本的 `mods` 文件夹。

## 安装名称与目录

选择加载器后会生成名称，例如 `1.21.1-NeoForge_21.1.81`。可以自行修改，已经手动填写的名称不会被后续选择反复覆盖。同名版本已存在时，需要换一个名称。

一次安装对应一个版本目录：原版 JAR 与合并后的 JSON 都放进最终安装目录，不额外留下一个仅供继承的原版版本。

`libraries` 和 `assets` 在游戏根目录下共享。存档和模组等数据按版本隔离，详见[版本选择](versions.md)。

## 文件下载源

在 **设置 → 下载 → 下载源** 中，有两个独立选项：

| 设置 | 用途 |
| --- | --- |
| 版本列表源 | 决定版本清单与加载器列表的首选来源。 |
| 文件下载源 | 决定游戏文件和安装依赖的首选来源。 |

两者都支持官方优先或镜像优先，失败时尝试另一来源。不是所有上游地址都有镜像，不会把任意自定义 URL 自动变成镜像链接。

## 多线程与限速

在 **设置 → 下载 → 多线程下载** 中调整最大连接数，范围 1～256；速度限制输入单位为 MiB/s，0 表示不限制。

连接数由同一下载任务内的文件和分段共用，不是每个文件各自占满全部连接。更多连接不一定更快，还会受服务器限流、磁盘和网络影响。

## 安装过程

任务依次准备版本 JSON、客户端、支持库、资源，以及所选加载器。需要安装处理器时会选择可用 Java，并在后台执行，不打开上游图形安装向导。

到[任务管理](tasks.md)中查看进度或取消。失败任务保留原因；移除后清理本次未完成目录。完成后回到版本选择页选择新版本，必要时刷新列表。

## 下载失败

先看任务里的具体文件和来源。HTTP 403 表示该服务拒绝请求，增加连接数通常无效；Java 处理器失败则应查看 `ELCL/logs/Log1.txt` 中的安装日志。

不要把失败任务留下的半成品当成已安装版本。补全可以恢复有下载地址的文件，不能替代缺失的加载器安装步骤。
