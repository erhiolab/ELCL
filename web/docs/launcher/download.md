# 下载并安装游戏

在下载页选择 Minecraft 版本，再选择需要的加载器，点击开始下载。目前支持 Forge、NeoForge、Fabric、Quilt、LiteLoader 和 OptiFine。安装作为一个任务出现在任务列表中，包括原版文件、加载器依赖和安装处理器。

选择加载器后自动生成版本名，例如 `1.21.1-NeoForge_21.1.81`。可以手动修改；自己填写的名称不会被下一次选择覆盖。同名版本已经存在时需要换一个名称。

加载器通常不能混装。选择不兼容的加载器会清除旧选择，目前只允许元数据明确兼容的 Forge + OptiFine。Fabric API、Quilt 的模组 API 和其他模组需要自行安装。

一次安装只创建一个可选版本目录。例如选择 NeoForge 后，原版 JAR 和合并后的完整 JSON 都保存在 `versions/1.21.1-NeoForge_21.1.81/`，文件名也使用这个安装名，不会额外创建 `versions/1.21.1/`。支持库和资源仍在游戏目录下共享，游戏数据按版本隔离。部分安装步骤需要 Java，启动器会从设置中的列表选择可用运行时；缺少 Java 时任务会提示，不会弹出上游图形安装向导。

下载使用“设置 → 下载”中的文件下载源、连接数和限速。文件进度按字节统计，处理器进度按安装步骤统计。安装输出写入启动器日志的 `Installer` 分类。

取消任务会停止下载并结束本次安装进程。失败任务留在列表中供查看，移除时清理本次未完成的版本和安装工作目录，保留已验证的共享文件。安装成功后登记安装档案，可以到版本选择页刷新并选择它。旧安装留下的原版目录不会被擅自删除，以免影响其他依赖它的版本。
