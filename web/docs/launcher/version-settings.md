# 版本设置

在启动页点击 **版本设置**，或点击版本列表某一行右侧的齿轮。页面管理打开时选定的版本，返回后回到原来的启动页或版本列表。

顶部显示图标、名称、说明和版本标签，与版本列表使用相同布局。左侧当前提供 **概览**。

## 修改版本名

在 **个性化** 卡片中点击修改版本名，输入名称并确认。

这会修改实际目录、同名 JSON 和 JAR、元数据的安装 ID，不只是改显示文字。存档、模组、配置和独立描述随目录保留，ELCL 的当前选择、文件夹记忆与安装档案也会同步。

已有同名目标不会覆盖。版本正在启动、运行、安装或补全时不能改名；被其他版本继承或引用客户端时也会阻止。

重命名失败会尝试恢复原名称和元数据。缺失或损坏 JSON 的目录也能改名，但不会因此变成可启动版本。

## 修改版本描述

在 **个性化** 中点击修改版本描述，最多填写 256 个字符。设置后，概览和版本列表第二行显示为：

```text
常用存档  [正式版] [1.21.1] [NeoForge 21.1.265]
```

留空并保存，会恢复默认版本类型说明。描述太长时省略显示；错误版本仍优先显示解析错误。

描述保存在版本目录的 `ELCL/settings.json`，不修改 Minecraft 的版本 JSON，也不写入全局配置。重新打开、移动或重命名版本后仍能读取；保存会保留其他扩展字段，损坏配置不会被直接覆盖。

目前独立文件保存描述，启动选项仍使用全局配置。

## 打开常用文件夹

可以快捷打开版本、存档、截图、光影、材质包和日志文件夹。带模组加载器或已有 `mods` 的版本，还会显示 Mod 文件夹入口。

子文件夹不存在时会创建；版本本身已经被移除时不会重建整个版本。所有入口都遵循版本隔离，打开的是当前版本内的数据。

## 补全文件

点击后创建任务，检查客户端、支持库、资源索引、日志配置和资源，按可用大小与 SHA-1 下载缺少或损坏的文件。

无需登录，不启动游戏，不删除存档或模组。来源、连接数和限速使用[下载设置](download.md)。

元数据无法读取，或加载器产物缺失又没有下载地址时，需要重新安装，补全不能代替安装处理器。

## 导出启动脚本

选择保存位置后，只生成一个 `.bat`，不在旁边创建附属文件夹。导出会选择 Java 并校验文件，不会当场执行启动前命令或游戏。

不要求登录，也不刷新 Microsoft 会话。使用所选账户的本地玩家名与 UUID，没有账户时使用离线玩家 `Player`；不会写入账户令牌，不提供正版在线会话。

执行时使用 Windows PowerShell 读取 BAT 内嵌的启动数据，兼容长参数和特殊字符。本地库与补丁留在版本的 `ELCL/export-runtime/` 下。

脚本仍依赖当前 Java、游戏目录与运行文件的绝对路径，不是可分发整合包。移动 Java 或版本后应重新导出。

运行脚本时才执行已配置的启动前命令，然后启动游戏；应用导出时的内存、参数、窗口标题、优先级和最大化选项。不刷新登录、不执行 ELCL 的内存优化，也不接入 ELCL 的运行任务列表。

## 删除版本

删除前需要确认。确认后删除整个版本目录，包括其中的存档、模组、配置和截图；共享支持库、资源和其他版本保留。

有相关任务或被其他版本引用时不能删除。成功后清除当前选择和 ELCL 登记的安装档案，刷新列表。请先备份需要保留的数据。

## 查看操作结果

进度和错误在[任务列表](tasks.md)中显示，重要操作写入日志。设置页面也可以打开任务列表，关闭任务页后回到版本设置。
