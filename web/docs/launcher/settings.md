# 外观与配置

普通设置修改后自动保存，通常不需要确认。导入配置、清理缓存等需要重启的操作会另行说明。

## 外观

入口：**设置 → 个性化 → 基础**。

可以切换浅色／深色主题、选择主题色和调整窗口不透明度。主题切换使用过渡效果，避免界面突然闪变。

## 语言

在基础卡片下方的语言卡片中选择界面语言。下拉列表以当前构建实际包含的语言为准，切换会刷新界面文字。

游戏本身的语言由 Minecraft 设置决定，这个选项只影响 ELCL。

## 容量与速度单位

可以选择二进制或十进制显示：

| 模式 | 换算方式 | 示例 |
| --- | --- | --- |
| 二进制，默认 | 每级 1024 | MiB、GiB、MiB/s。 |
| 十进制 | 每级 1000 | MB、GB、MB/s。 |

选择会影响内存分配、性能页面和任务下载速度等相关显示。百分比按实际字节计算；自动内存分配的档位也按所选单位换算。

## 启动器标题栏

可以隐藏标题、使用默认标题，或填写自定义文字。它控制 ELCL 窗口，不是游戏窗口；游戏标题在[启动设置](launch-settings.md)中修改。

## 导出配置

入口：**设置 → 其他 → 配置**。点击导出，选择保存位置；默认文件名为当前日期与时间，例如 `2026-11-10_14-30-00.json`。

导出的是全局启动器设置，包括已添加的游戏文件夹和 Java 路径，不复制游戏文件、账户令牌、独立版本描述或匿名安装 ID。

## 导入配置

选择导出的 JSON。ELCL 会检查内容并规范化设置值，成功后提示重启，然后自动重启以完整应用配置。

无效文件不会被当成有效设置继续应用。导入其他电脑的配置后，记得检查游戏目录和 Java 路径是否仍然存在。

## 重置设置

设置页提供对应分区的重置入口。重置启动设置会重新获取 Java；重置不会卸载游戏、删除存档或删除账户文件。

独立版本描述保存在各版本目录的 `ELCL/settings.json`，不属于全局配置重置。

## 调试界面

**设置 → 调试**可以预览不同级别的弹窗、通知条和通知压力测试。它用于检查 ELCL 界面，不是 Minecraft 的调试设置。
