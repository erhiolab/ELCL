# 外观与配置

普通设置修改后自动保存，通常不需要确认。导入配置、清理缓存等需要重启的操作会另行说明。

设置页的普通选项统一使用标签与控件两列布局，选项行和卡片之间保留一致间距。较长说明会换行或通过悬浮提示显示，避免与控件重叠。

## 外观

入口：**设置 → 个性化 → 基础**。

个性化页面依次为 **基础**、**标题栏**、**背景**、**容量单位**、**社区资源**。

基础中可以切换浅色／深色主题、选择主题色和调整窗口不透明度。主题切换使用过渡效果，避免界面突然闪变。

## 语言

在 **设置 → 个性化 → 基础** 中选择界面语言。下拉列表以当前构建实际包含的语言为准，切换会刷新界面文字。

游戏本身的语言由 Minecraft 设置决定，这个选项只影响 ELCL。

Mods 汉化只在中文界面可用。切到其他语言时，汉化开关会锁定关闭，下载文件名也恢复使用原名；切回中文后恢复之前的汉化偏好与文件名格式。Mods 详情中的 **MC 百科** 按钮也只在中文界面显示。

## 启动器标题栏

可以隐藏标题、使用默认标题，或填写自定义文字。它控制 ELCL 窗口，不是游戏窗口；游戏标题在[启动设置](launch-settings.md)中修改。

## 自定义背景

**设置 → 个性化 → 背景** 保留 **显示背景** 总开关。点击 **背景管理** 后，上方调整播放和外观，下方在本地或 Wallpaper Engine 图库选择素材。详见[背景管理](backgrounds.md)。

## 容量与速度单位

在 **设置 → 个性化 → 容量单位** 中，可以选择 **二进制** 或 **十进制**：

| 模式 | 换算方式 | 示例 |
| --- | --- | --- |
| 二进制，默认 | 每级 1024 | MiB、GiB、TiB；MiB/s、GiB/s。 |
| 十进制 | 每级 1000 | MB、GB、TB；MB/s、GB/s。 |

容量和速度达到下一级阈值时会自动升档，例如 1024 GiB 显示为 1.0 TiB，1000 GB 显示为 1.0 TB；更大的数值会继续升档。

选择会影响内存分配、性能页面、内存优化与清理结果，以及任务下载速度等相关显示。百分比按实际字节计算；自动内存分配的档位也按所选单位换算。

## 社区资源

在 **设置 → 个性化 → 社区资源** 中，可以设置：

| 选项 | 效果 |
| --- | --- |
| Mods 汉化 | 中文界面默认开启，使用 MC 百科译名显示 Mods 名称，并支持中文名称搜索；关闭后保留来源或 Mods 文件中的原名，不再查询汉化信息。其他语言下锁定关闭。 |
| Mods 列表样式 | 决定本地 Mods 列表优先显示名称还是文件名，与 Mods 汉化开关独立。 |

返回 Mods 页面时会应用当前设置，已有译名缓存不会被删除。重置个性化设置会恢复中文界面、开启 Mods 汉化并使用名称优先的列表样式。

社区资源下载源与 Mods 文件名格式仍在 **设置 → 下载** 中。原始文件名为默认值；只有中文界面且 Mods 汉化开启时，才能选择在下载文件名中加入中文名，其他情况下该选项禁用并显示原始文件名，不改动之前保存的格式。社区资源下载源不受语言限制。重置下载设置只恢复这些下载相关选项，不修改汉化偏好或 Mods 列表样式。

这些设置会随配置导入／导出。操作方式与限制见[下载与管理 Mods](mods.md#下载源、文件名与列表样式)。

## 导出配置

入口：**设置 → 其他 → 配置管理**。点击导出，选择保存位置；默认文件名为当前日期与时间，例如 `2026-11-10_14-30-00.json`。

导出的是全局启动器设置，包括已添加的游戏文件夹，不包含本机 Java 列表、Java 排序、移除记录及安装来源，也不复制游戏文件、账户令牌、独立版本描述、匿名安装 ID 或协议与统计选择。

## 导入配置

选择导出的 JSON。ELCL 会检查内容并规范化设置值，成功后提示重启，然后自动重启以完整应用配置。

无效文件不会被当成有效设置继续应用。导入其他电脑的配置后，记得检查游戏目录是否仍然存在。本机 Java 列表保存在 `ELCL/java.json`，不会被导入配置覆盖；配置文件中的 Java 数据不参与导入。新电脑会自行查找 Java，也可以在启动设置中手动添加。

## 文件关联

入口：**设置 → 其他 → 文件关联**。

- **绑定 .mrpack**：将当前 ELCL 添加为整合包打开方式。设为默认后，双击 MRPACK 文件会打开 ELCL 并显示现有的安装确认弹窗，确认名称后才创建安装任务。
- **取消绑定**：移除当前 ELCL 写入的打开方式，并在普通扩展名关联仍由 ELCL 使用时恢复此前的值。不会清理其他应用的打开方式。
- **默认应用设置**：打开 Windows 设置，按 `.mrpack` 查找并选择需要的应用。

Windows 已有受保护的默认程序时，绑定不会强制覆盖它。ELCL 会提示并打开系统设置，由你选择 ELCL；取消绑定后，若系统默认项仍指向 ELCL，也需要在这里另选应用。页面会显示当前关联状态。

关联只对当前 Windows 用户生效，不需要管理员权限，不关联 ZIP。它不保存在 ELCL 的通用配置中，导入、导出和重置配置不会绑定或取消文件关联。移动启动器后，请在新位置重新绑定。另一份 ELCL 写入的关联不会被当前启动器直接取消。

已有同一目录、同一 Windows 用户会话的 ELCL 运行时，会把文件转交给原窗口并恢复最小化窗口，不再打开第二个启动器窗口。同一账户下，普通权限打开的文件也可以交给以管理员权限运行的 ELCL。没有运行实例或无法转交时，由新窗口处理。多个文件依次显示安装确认，正在处理或等待处理的同一路径不会重复弹出。

## 重置设置

设置页提供对应分区的重置入口。重置启动设置会恢复启动选项，但保留本机 Java 列表、顺序、移除记录和安装来源；重置不会卸载游戏、删除存档或删除账户文件。

独立版本描述保存在各版本目录的 `ELCL/settings.json`，不属于全局配置重置。

## 调试界面

在 **设置 → 调试 → 启动器日志**，点击 **打开当前日志**，可以实时查看本次 ELCL 运行写入的 `Log1.txt`。下面的 `Log2.txt` 至 `Log5.txt` 是之前的会话，编号越大越早。历史日志不会持续刷新，尚未生成的文件不能打开。

查看器可以筛选警告和错误、搜索或复制内容。点击 **打开日志文件** 可用记事本查看完整文件。**清空显示** 只清除当前视图，不会删除磁盘里的日志。

调试页也提供弹窗、通知条预览与通知压力测试。这里查看的是 ELCL 本身的日志；游戏输出请到[任务管理](tasks.md#查看实时-minecraft-日志)或[版本设置](version-settings.md#查看版本日志)。
