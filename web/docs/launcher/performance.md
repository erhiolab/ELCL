# 性能

入口：**更多 → 性能**。按硬件分别展示系统状态，适合快速查看运行游戏前后的占用。

## 处理器

显示型号、物理核心和逻辑线程数，以及系统和 ELCL 自身的 CPU 使用率。

Windows 提供两种能效等级时，会额外显示性能核和能效核数量；没有足够系统信息时只显示总数，不根据型号猜测。

系统使用率优先采用 Windows 的处理器效用计数器，与现代任务管理器采用同类指标；不可用时回退到忙碌时间并记录日志。首次进入需要等待采样，刷新间隔不同也可能让两边读数不完全一致。

## 内存

显示物理内存总量、已用、可用和 ELCL 内存占用，色条表示系统内存使用比例。

它反映整台机器的状态，不表示 Java 堆内存；ELCL 也不会在这里替每个游戏统计堆占用。

## 显卡

列出系统报告的硬件图形适配器，并根据集成属性标注核显或独显。虚拟显示适配器和软件渲染器会过滤。

通过 DXCore 获取；系统或驱动不支持时会显示读取失败并记入日志。目前不提供 GPU 实时负载、显存占用或温度。

## 磁盘与系统

磁盘卡片显示当前游戏目录所在卷的已用、可用和总容量；系统卡片显示操作系统版本、系统架构和 ELCL 进程架构。

容量按各项数值自动选择单位，达到阈值后显示 TB 或 TiB，更大的容量继续升档。使用二进制还是十进制，取决于[个性化设置](settings.md#容量与速度单位)中的选择。

## 刷新间隔

在处理器卡片右上角选择 0.5、1、2、5 或 10 秒，设置会保存并用于实时读数。离开页面后停止周期采集，重新进入再开始。

某项采集失败不会停止其他卡片，失败和恢复会写入日志，不会不断弹出通知。
