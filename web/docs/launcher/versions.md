# 版本选择与游戏文件夹

在启动页打开 **版本选择**。左边选择游戏文件夹，右边显示其中的已安装版本。

## 默认游戏文件夹

首次运行时，ELCL 会在启动器旁创建 `.minecraft`，并列出当前文件夹和官方启动器的默认游戏文件夹。游戏目录采用标准结构：

```text
.minecraft/
├─ versions/
│  └─ 我的版本/
│     ├─ 我的版本.json
│     └─ 我的版本.jar
├─ libraries/
└─ assets/
```

选择的应是包含 `versions` 的游戏根目录，不是某个版本子目录。其他启动器的标准 `.minecraft` 可以添加；Prism 的实例布局不会被自动转换。

## 添加已有文件夹

点击左侧添加文件夹，选择游戏根目录。添加后会扫描 `versions` 下的目录。

左侧列表上的齿轮或右键菜单提供文件夹管理操作，例如修改显示名称、打开和刷新目录。修改显示名称只改变 ELCL 中的称呼，不会移动磁盘目录。固定的官方入口有相应操作限制。

## 选择一个版本

点击游戏文件夹后，ELCL 优先恢复这个文件夹上次使用的有效版本；没有可恢复的选择时，选中扫描结果中的第一个有效版本。文件夹内没有版本时显示空状态，不沿用另一个文件夹的游戏。

单击版本可以选择它。鼠标移到条目上时，右侧会出现删除和设置按钮；齿轮打开的是那一行的版本设置，不会替你切换当前启动版本。

## 名称、描述和标签

版本名称来自安装元数据。游戏版本与加载器信息主要根据 JSON 的结构化字段读取，不会简单把自定义名称里的数字当作版本。

在[版本设置](version-settings.md)中添加描述后，第二行显示为：

```text
常用存档  [正式版] [1.21.1] [NeoForge 21.1.265]
```

未设置描述时，继续显示版本类型说明和版本标签。

## 红色错误条目是什么

空目录、缺少 JSON、JSON 损坏或无法读取的版本也会保留在列表中，并显示错误图标与原因。

这些目录可以打开设置、重命名或删除，但不能启动、导出脚本或补全文件。错误原因会优先于自定义描述显示。文件能解析也不代表资源完整，启动时仍会校验。

## 游戏数据放在哪里

ELCL 固定使用版本隔离。存档、模组、配置、截图、材质包和游戏日志放在各自的版本目录中；`libraries` 与 `assets` 在游戏根目录下共享。

更详细的目录说明见[文件与故障排查](files.md)。
