# 账户管理

在启动页点击 **点击打开账户管理**。左侧是账户列表，右侧可以添加账户、使用所选账户或删除账户。

## 添加 Microsoft 账户

1. 点击 **添加 Microsoft 账户**。
2. ELCL 会打开登录网页，并复制设备代码。展开区域也会显示代码。
3. 在网页上完成 Microsoft 登录和授权，回到 ELCL 等待验证完成。

如果网页没有打开，可以再次打开登录页；代码没有复制成功，也可以手动复制。等待期间可以取消登录，代码过期后需要重新开始。

网页显示成功后，ELCL 还要交换 Xbox 与 Minecraft 会话、检查 Java 版授权并读取玩家档案。网页授权成功不等于整个登录流程已经完成。

## 添加离线账户

点击 **添加离线账户**，填写玩家名并确认。名字需要 3～16 个字符，只能使用英文字母、数字和下划线，同一名称不能重复添加。

ELCL 根据名字生成离线 UUID，相同大小写的名字会得到相同结果。离线账户可以用于单人游戏和不要求在线验证的服务器，不提供皮肤和披风管理。

## 选择正在使用的账户

单击列表项可以查看它；点击 **使用此账户** 才会切换启动账户。也可以直接双击列表项，立即切换。

列表会持续标出正在使用的账户。重新打开页面时，会定位到当前账户。玩家名旁的信息图标可以查看 UUID，无需在主界面一直显示它。

## 删除账户

选择账户后点击删除，并确认提示。删除只移除 ELCL 本地保存的记录，不会注销 Microsoft 账户或删除 Minecraft 购买记录。

如果删掉正在使用的账户，下次启动游戏前需要重新选择。Microsoft 账户重新添加时需要再次登录。

## 账户保存在哪里

账户单独保存在 `ELCL/accounts.json`，不包含在配置导出或配置重置中。Microsoft 令牌使用 Windows 当前用户的数据保护机制保存，复制文件到另一台电脑或另一个 Windows 用户下，不能保证可以继续使用。

请不要公开分享账户文件。头像和外观的使用方法见[皮肤与披风](appearance.md)。
