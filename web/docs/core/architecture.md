# Core 负责什么

一句话：**Core 做可以在不同启动器里复用的事，界面和用户习惯留给调用方。**

例如，Core 可以读取 Mojang 的版本清单并告诉你有哪些版本；你的程序决定把它们排成什么样、什么时候刷新，以及出错时怎样提醒用户。

| Core 做 | 你的程序做 |
| --- | --- |
| 查询和解析游戏、加载器版本 | 决定首选来源与展示方式 |
| 查找和验证 Java | 保存用户排序、选择与排除项 |
| 合并版本 JSON、收集依赖、解压本地库、生成参数 | 读取启动设置、执行命令、管理进程与窗口 |
| 按给定地址下载文件、报告进度 | 选择保存目录、组织游戏安装任务 |
| 在给定路径写日志或 JSON | 定义配置字段和默认值 |
| 返回数据或抛出错误 | 告诉用户出了什么问题、是否重试 |

Core 不引用 WPF，也不读取 ELCL 的配置文件。网络请求需要你传入 `HttpClient`；文件操作需要你传入路径。这样同一份库才能放进别的 .NET 10 程序。

Core 提供账户登录请求、原版下载计划和启动参数生成，但不替调用方管理整个启动流程。调用方需要验证账户、下载缺失文件、选择 Java，再创建和观察进程；Forge 等加载器的安装器与处理器不在当前实现范围内。
