# ELCL v0.0.1 与 ELCLC v0.0.1

这是 ELCL 和 ELCLC 的第一个公开版本。ELCL 是 Windows 上的 Minecraft Java 版启动器；ELCLC 是可以单独引用的 .NET 10 核心库。

## ELCL v0.0.1

### 安装、启动与管理游戏

- 安装原版，以及 Forge、NeoForge、Fabric、Quilt、LiteLoader 和 OptiFine。可以选择下载来源，也能在任务列表查看进度、取消任务或检查失败原因。
- 支持 Microsoft 账户和离线账户。Microsoft 账户可以预览和更换皮肤、切换披风。
- 可以添加已有游戏文件夹。存档、Mods 和配置按版本隔离，资源与支持库在同一个游戏目录下共享。每个版本都可以设置自己的 Java、内存和启动参数。
- 可以查找或下载安装 Java，运行多个游戏实例，查看每个进程的实时日志，也可以在版本设置里回看历史日志。

### Mods 与整合包

- 在 CurseForge 和 Modrinth 搜索 Mods，按游戏版本和加载器筛选。版本设置支持从文件安装、拖入、启停和删除本地 Mods。
- 支持导入 Modrinth、CurseForge 和 MultiMC 格式整合包。导出时可以挑选具体文件，生成 MRPACK，或另外打包一份 ELCL。Windows 下可把 MRPACK 关联到启动器。

### 个性化与工具

- 支持白昼和深夜主题，以及图片、视频背景。背景图库支持多级目录与视频首帧封面，可以固定背景、启动时随机选取或定时轮播。
- 提供硬件占用概览、自定义文件下载、缓存清理和内存优化，也可以导出和导入启动器配置。

第一次使用可以从[启动器指南](../launcher/index.md)开始。Windows x64 有两个版本：自带 .NET 的版本可直接运行；较小的版本需要先安装 .NET 10 Windows Desktop Runtime。两者都需要为 Minecraft 准备兼容的 Java。

## ELCLC v0.0.1

- **版本与安装：** 查询和扫描游戏版本，生成原版与加载器的安装计划，处理下载、文件校验和来源回退。
- **启动：** 查找和验证 Java、查询 Java 发行版本、解析版本继承与启动参数，并准备游戏资源。库不会替调用方启动游戏进程。
- **账户：** 计算离线 UUID；支持 Microsoft 设备代码登录和会话刷新，以及读取与修改皮肤和披风。使用 Microsoft 登录时，应用注册信息由调用方提供。
- **社区资源：** 查询 CurseForge 和 Modrinth、解析依赖、管理本地 Mods，并导入或导出受支持的整合包格式。
- **通用工具：** 多文件并发下载与进度回调、会话日志、JSON 文件读写和 Minecraft Wiki 查询。

核心库不依赖 WPF。可以引用源码项目，或在 .NET 10 项目中引用发布附带的 DLL。接入方式见[快速开始](../core/quick-start.md)，方法签名见[公开 API 索引](../core/api.md)。初版 API 仍可能调整。
