# 百宝箱

更多 > 百宝箱提供自定义文件下载. 输入 HTTP 或 HTTPS 地址后, 页面从 URL 路径填入文件名; 可以手动修改. 未填写有效 HTTP(S) 地址时'开始下载'不可用. 选择保存文件夹后, 点击'开始下载'创建任务, 页面右下角随即出现任务管理按钮. 百宝箱保留'打开文件夹'入口; 进度和取消操作在任务管理页. 目标文件已存在时会先询问是否覆盖. 服务器是否返回 404/403 由实际下载请求判断.

启动器从[下载设置](settings.md)读取最大连接数和速度限制, 并将它们传给 Core 的[通用下载器](../core/downloader.md). 自定义下载仅有用户输入的一个地址; 部分网站会拒绝直接下载并返回 403, 此时页面显示失败通知.

启动器的 `LauncherTaskManager` 保存任务及阶段状态; 自定义文件下载目前只有'下载文件'一个阶段. 后续版本安装/模组下载可以创建包含多个阶段的任务. 阶段通过通用 `LauncherTaskContext` 调用共享 `DownloadManager`, 下载请求按入队顺序运行. 成功任务完成提示后自动移除; 若列表因此变空, 任务管理页自动返回. 失败任务留在列表中显示错误, 用户可手动移除. 任务列表不会在重新启动后恢复.

百宝箱的输入框和任务管理界面属于 ELCL; Core 仅处理文件传输/校验/取消及来源回退.
