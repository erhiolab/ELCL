# 左下角通知条

启动器界面通过 `LauncherToasts.Information`/`Success` 和 `Error` 发送蓝色/绿色和红色通知. 通知不阻塞操作, 从左下角向上弹出, 4 秒后淡出. 多条通知在页面区域叠放, 超出页面高度的部分会被裁剪, 不覆盖标题栏.

每次调用 `LauncherToasts.Information`/`Success` 或 `Error` 都独立创建通知视图/入场动画和到期计时器. 计时器在到期时停止, 该通知单独退场并从界面移除.

设置 > 调试的卡片可以分别触发三种通知. 性能测试以 25 毫秒为目标间隔随机触发一条通知, 直到 1000 条全部发出; 实际节奏会受界面负载影响. 发出过程交还界面线程处理绘制和输入, 每条通知仍分别执行计时和动画; 测试进行时按钮显示进度并防止重复启动. 通知条实现位于启动器项目, 不依赖 Core.
