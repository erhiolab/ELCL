# 桌面端视觉方向

## Night Circuit

ELCL 使用名为 Night Circuit 的独立视觉方向: 深色空间/`#80CEFF` 浅蓝识别色与克制的细线框架.

## UI 底座

桌面端使用 [WPF-UI](https://github.com/lepoco/wpfui) 4.3.0 提供现代 WPF 控件/图标和窗口底层能力. 页面布局/颜色/控件模板与动画由 ELCL 自行设计, 不直接套用默认 NavigationView 外观.

## 当前范围

主窗口只负责窗口外壳/顶部导航/侧栏容器与页面容器. 每个一级页面分别提供自己的侧栏和主体视图, 并声明所需侧栏宽度; 正数表示固定宽度, 0 表示根据侧栏内容自动调整, 最小宽度为 135. 顶部导航切换时同时替换两个区域. 下划线使用 300 毫秒缓出过渡, 侧栏宽度使用 360 毫秒先快后慢并轻微回弹的过渡. 按钮悬停背景在 160 毫秒内渐显, 离开时在 140 毫秒内渐隐; 侧栏列表选中背景和左侧竖线在 320 毫秒内一起上下移动, 背景经过其他选项时暂时降低不透明度. 页面内容过渡留待后续实现.

一级页面的侧栏/主体对应关系集中在 `Navigation/ShellRouteCatalog.cs`, 字体图标字形和矢量图标集中在 `Icons/LauncherIcons.cs`; `MainWindow` 只执行路由切换和窗口动效.
